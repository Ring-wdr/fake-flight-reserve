# 항공권 다크패턴 재현 데모

항공권 예약 과정에서 겪은 기만 수법과 일반적으로 알려진 다크패턴을 재현한 데모입니다. 실존 기업의 이름과 로고를 쓰지 않으며, 모든 항공사와 판매사는 가상입니다. 특정 업체의 실제 동작을 기록한 자료가 아닙니다.

- 실제 판매와 결제가 없습니다. 서버도 없어 입력 정보가 어디에도 전송되지 않습니다.
- 여권과 카드 입력칸은 읽기 전용이고, 샘플 데이터 버튼으로만 채워집니다.
- 진행 상태는 브라우저 localStorage에만 저장됩니다.

## 실행

```bash
pnpm install
pnpm build
pnpm preview   # http://localhost:5199
```

## 판매처별 수법 조합

| 판매처 | 화면 구성 | 수법 조합 | 재현 영상 |
| --- | --- | --- | --- |
| Faretrap | 2단계, 한 화면 입력 | 가격 인상 → 이탈 유도 메일 → 결제 후 취소, 초고속 발권 권유, 30분 타이머 | `evidence/faretrap.mp4` |
| Voyagate | 3단계, 하단 고정 가격 바 | 1인당 가격 표기 → 이탈 유도 메일 → 가짜 확정 메일 → 발권 지연 | `evidence/voyagate.mp4` |
| Pinefly | 6단계 스테퍼 | 가격 고정 권유, 단계별 끼워팔기 → 판매 종료로 목록 이동 → 결제 후 취소 → 환불 지연, 10분 타이머 | `evidence/pinefly.mp4` |

| Truefare | 2단계, 정상 동작 비교군 | 표시 가격 그대로 결제 → 즉시 발권. 옵션 미선택, 타이머 없음, 재검색해도 같은 가격 | `evidence/truefare.mp4` |

재현 패널의 시나리오를 바꾸면 수법 판매처 세 곳에서 수법 하나만 따로 볼 수 있습니다. Truefare는 어떤 시나리오에서도 정상으로 동작합니다.

Truefare의 표시 가격은 네 곳 중 가장 높습니다. 다른 세 곳에 필수 수수료를 더한 금액보다도 높지만, 미리 선택된 옵션이나 가격 인상이 붙으면 다른 곳의 최종 결제 금액이 더 비싸질 수 있습니다.

## 판매사 자체 목록

가격 변동이나 판매 종료, 결제 중단, 이탈 유도 메일 뒤에는 메타 검색이 아니라 해당 판매사의 자체 목록(`/sites/:siteId/list`)으로 이동합니다. 이 목록에서도 검색할 수 있으며, 판매처마다 달라지는 것은 문구와 가격 표기뿐입니다.

- `src/domain/offers.ts`: 목록 생성 로직. 판매처를 추가해도 그대로 쓰며, `honest` 판매처는 실제 가격을 그대로 보여 줍니다.
- `src/components/SearchFields.tsx`: 메타 검색과 판매사 목록이 함께 쓰는 검색 입력.
- `src/pages/seller/SellerList.tsx`: 공통 목록 상태와 화면.

목록 규칙은 다음과 같습니다.

- 기준가는 사용자가 앞서 본 가격입니다. 판매사 목록에서 새로 검색하면 그 조건의 최저가와 판매처 차액을 더한 값이 됩니다.
- 기준가 상품은 50% 확률로만 목록에 포함됩니다.
- 나머지 상품은 모두 기준가보다 비쌉니다.
- 판매 종료된 항공편은 기준가로 다시 나오지 않습니다.

## 재현하는 수법

| 수법 | 재현 내용 |
| --- | --- |
| 가짜 가격 변동 | '9석 남음'을 보고 여권 정보를 입력하면 가격이 오르거나 목록으로 돌려보냄 |
| 이탈 유도 메일 | 결제를 중단하면 '원래 가격' 메일이 오지만, 링크를 누르면 판매 종료 |
| 가짜 상품 | 결제 후 예약 조회에는 '발권 진행 중'으로 나오다가, 2~3시간 뒤 취소 문자와 메일이 오고 조회 결과도 '예약 취소됨'으로 바뀜 |
| 가짜 확정 메일 | '확정' 메일을 받아도 예약 조회는 '발권 진행 중'이고 전자티켓 번호가 없으며, 72시간 뒤 발권 지연으로 바뀜 |
| 가짜 긴급성 | 고정된 잔여 좌석, 난수 시청자 수, 새로고침하면 돌아가는 타이머 |
| 숨은 요금·끼워팔기 | 미리 체크된 옵션, 1인당 가격 표기, 결제 직전 수수료 |
| 환불·상담 지연 | 같은 답을 반복하는 상담봇, '최대 30일' 환불 |

오른쪽 아래 재현 패널에서 시간을 건너뛰고, 메일함과 휴대폰을 열 수 있습니다. '수법 해설 표시'를 켜면 화면마다 설명이 나타납니다.

## 가격 계산

검색 입력은 모두 가격에 반영됩니다. 가격은 재현용 계수로 계산한 값이며 실제 운임이 아닙니다(`src/domain/flights.ts`).

| 입력 | 반영 방식 |
| --- | --- |
| 편도/왕복 | 왕복은 출발편과 귀국편을 차례로 고르며, 귀국 구간을 합산 |
| 승객 | 성인 100%, 어린이 75%, 유아 10%. 수수료와 옵션은 좌석 수만큼 |
| 좌석 등급 | 이코노미 1배, 프리미엄 이코노미 1.6배, 비즈니스 3.2배, 일등석 5배 |
| 노선 | 공항 간 거리 계수 |
| 날짜 | 12월 20일 이후 25%, 금·토요일 출발 8% 할증 |

## 폴더 구조

```
src/
  main.tsx
  app/         라우터(router.tsx), 공통 레이아웃, 경로 생성(paths.ts), 이동 함수(navigation.ts)
  components/  여러 화면이 쓰는 UI (재현 패널, 검색 입력, 스켈레톤, 해설 등)
  domain/      항공편과 가격 계산, 판매사 목록 생성
  state/       앱 상태와 수법 진행 로직
  sites/       판매처별 설정과 스타일
  pages/       flights(메타 검색), seller(판매사 공통 화면), mail, lookup
  styles/      공통 스타일
```

라우팅은 `react-router-dom`의 `createHashRouter`를 라이브러리 방식으로 씁니다. GitHub Pages에서도 새로고침과 직접 링크가 동작하도록 해시 URL을 유지합니다.

## 판매처 추가하기

라우터와 페이지는 수정하지 않습니다.

1. `src/sites/<id>/index.ts`에 `SiteConfig`를 작성합니다. 필요하면 같은 폴더에 `site.css`를 두고 `.site-<id>` 아래에 스타일을 적습니다.
2. `src/sites/index.ts`의 `SITE_LIST`에 등록합니다.

등록하면 `/sites/<id>/*` 경로, 예약 옵션 목록, 자사 목록, 결제, 메일이 자동으로 연결됩니다. 주요 설정은 다음과 같습니다.

| 설정 | 역할 |
| --- | --- |
| `flow` | 결제 전 예약 단계와 순서. `summary`, `passenger`, `fare`, `bags`, `seat` 중에서 고르며 `passenger`를 포함해야 합니다. 마지막 단계에서 가격을 재확인합니다. |
| `header` | 진행 표시 방식. `steps`(2단계), `wizard`(단계 n/m), `stepper`(단계 목록) |
| `enter` | 판매사로 넘어올 때의 전환 화면. `skeleton`, `spinner`, `ticket` |
| `mix` | 수법 조합. 가격 변동(`price`), 이탈 유도 메일(`lure`), 결제 후 처리(`after`) |
| `extras` | 유료 옵션과 기본 선택 여부. `fare` 단계에는 `flexi`, `seat` 단계에는 `seat`, `bags` 단계에는 `bag` 옵션이 필요합니다. |
| `honest` | 정상 판매처 여부. 패널 시나리오의 영향을 받지 않고 목록에 실제 가격을 보여 줍니다. |

새로운 종류의 단계가 필요할 때만 `FlowStep` 타입과 `src/pages/seller/StepRoute.tsx`의 `STEP_PAGES`에 화면을 추가합니다.

## 이름 바꾸기

메타 검색, 메일, 결제 앱 이름은 `src/sites/brand.ts`에서, 판매처 이름은 각 판매처 폴더에서 관리합니다.

## 재현 영상 만들기

`pnpm preview`를 켠 상태에서 실행합니다. 결과는 `evidence/`에 저장됩니다. 실행 전에 스크립트 안의 `/path/to/fake-flight-reserve`를 이 프로젝트의 절대 경로로 바꿔야 합니다.

```bash
ego-browser nodejs < scripts/replay.mjs
cd evidence
for s in faretrap voyagate pinefly truefare; do
  ffmpeg -y -f concat -safe 0 -i $s/frames.txt -vf "fps=15,format=yuv420p" -c:v libx264 -crf 22 $s.mp4
done
```

`scripts/verify.mjs`는 가격 반영, 스켈레톤, 영상에 없는 분기, 모바일 레이아웃을 확인합니다.
