# 항공권 다크패턴 재현 데모

항공권 예약 과정에서 겪은 기만 수법을 재현한 데모입니다. 실존 기업의 이름과 로고를 쓰지 않으며, 모든 항공사와 판매사는 가상입니다.

- 실제 판매와 결제가 없습니다. 서버도 없어 입력 정보가 어디에도 전송되지 않습니다.
- 여권과 카드 입력칸은 읽기 전용이고, 샘플 데이터 버튼으로만 채워집니다.
- 진행 상태는 브라우저 localStorage에만 저장됩니다.

## 실행

```bash
pnpm install
pnpm build
pnpm preview   # http://localhost:5199
```

## 재현하는 수법

| 수법 | 재현 내용 | 패널의 시나리오 |
| --- | --- | --- |
| 가짜 가격 변동 | '9석 남음'을 보고 여권 정보를 입력하면 가격이 오르거나 목록으로 돌려보냄 | 가짜 가격 변동 |
| 이탈 유도 메일 | 결제를 중단하면 '원래 가격' 메일이 오지만, 링크를 누르면 판매 종료 | 이탈 유도 메일 |
| 가짜 상품 | 결제 승인 후 2~3시간 뒤 취소 문자와 메일 도착 | 가짜 상품 |
| 가짜 확정 메일 | '확정' 메일의 예약번호가 항공사에서 조회되지 않고, 72시간 뒤 발권 지연 | 가짜 확정 메일 |
| 가짜 긴급성 | 고정된 잔여 좌석, 난수 시청자 수, 새로고침하면 돌아가는 타이머 | 모든 시나리오 |
| 숨은 요금·끼워팔기 | 미리 체크된 옵션, 결제 직전 수수료와 초고속 발권 권유 | 모든 시나리오 |
| 환불·상담 지연 | 같은 답을 반복하는 상담봇, '최대 30일' 환불 | 고객센터 화면 |

오른쪽 아래 재현 패널에서 시나리오를 고르고, 시간을 건너뛰고, 메일함과 휴대폰을 열 수 있습니다. '수법 해설 표시'를 켜면 화면마다 설명이 나타납니다.

## 이름 바꾸기

표시되는 서비스 이름은 `src/brand.ts`에서 관리합니다.

## 재현 영상 만들기

`pnpm preview`를 켠 상태에서 실행합니다. 결과는 `evidence/`에 저장됩니다. 실행 전에 스크립트 안의 `/path/to/fake-flight-reserve`를 이 프로젝트의 절대 경로로 바꿔야 합니다.

```bash
ego-browser nodejs < scripts/replay.mjs
cd evidence && ffmpeg -y -f concat -safe 0 -i frames.txt -vf "fps=15,format=yuv420p" -c:v libx264 -crf 22 full-journey.mp4
```

`scripts/verify.mjs`는 영상에 없는 분기와 모바일 레이아웃을 확인합니다.
